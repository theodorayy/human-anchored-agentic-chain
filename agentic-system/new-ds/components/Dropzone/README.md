# Dropzone
The dashed upload target that the old way of verifying identity relies on, and that Sisyphus replaces with a tap.

- `sy-drop`: `surface-wash` fill, 1.5px dashed `ink-faint` outline, 14px radius; arrow icon in `ink`, title `ui-body` medium, size limits in `ui-caption`.
- The dashed outline is decorative (1.9:1); the title and arrow carry the meaning. The consumer provides the accepted formats and the file handler.
- Use it to depict friction in problem slides; in the product, offer it only as the fallback after passport tapping.
