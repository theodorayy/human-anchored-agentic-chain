# ApprovalCard
The hand-back moment: the assistant pauses and asks the person to approve or edit before anything is submitted.

- Gold pause disc, title "Your turn" (`ui-body` medium), sub-line in the assistant's first person ("Approve before I submit"), then a gold "Approve" and an outline "Edit" pill.
- Connect it to the form it belongs to with a dashed `gold` `sy-link`.
- The consumer provides the pending action's wording and both handlers. The assistant never submits without this card.
