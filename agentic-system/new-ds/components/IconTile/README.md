# IconTile
An organisation or credential type as a 64px rounded tile (14px radius, 1px `border`), a single-ink line icon and a caption beneath.

- Icons are line icons: 24px grid, 1.8px stroke, round caps and joins, stroked in `ink`; no fills, no emoji. Icons here (phone, bank, shield, wifi, house) are drawn to the deck's style because no icon files were supplied.
- The gold "ID" badge (`gold` disc, `on-gold` text, 700 8px) means "this one asks you to prove who you are"; omit it for recipients.
- The consumer provides the icon path and the caption (`ui-label`, `ink-muted`).
