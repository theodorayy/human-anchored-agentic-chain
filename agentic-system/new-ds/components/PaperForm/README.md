# PaperForm
A paper government form drawn as the villain of the story: black section bars, boxed fields, one cell per SSN digit.

- Use for problem slides only. Sheet is `paper` (always white), lines and bars are `night`, SSN cells that block people are `paper-alert`.
- Tilt it ±3° with `shadow-float` in collages. Never reuse this look for Sisyphus's own screens, which use `FormCard`.
- The consumer provides the form name and field captions; use a real form's public title only when it is the subject of the slide.
