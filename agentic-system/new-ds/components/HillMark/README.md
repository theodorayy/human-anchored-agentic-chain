# HillMark
Sisyphus's motif: one long curve that starts flat and climbs to the right, with a `gold` disc resting on it. The effort is the story, so the ball is never at the top.

- Hero: 5px `ink` curve running edge to edge near the bottom of the slide, `gold` ball (diameter about 7% of slide width) a little right of centre. Section slides keep the same ball and curve and change only what sits above them.
- Footer progress: a 2px `border` curve, about 210px wide, bottom-right, with a 14px `gold` dot; the dot moves further right on each slide to show progress.
- The ball is a perfect circle sitting on the line, never dropped into it and never with a shadow.
- There is no logo mark: the name is set in plain `display-xl` type, and this motif is the only illustration of the brand idea.
