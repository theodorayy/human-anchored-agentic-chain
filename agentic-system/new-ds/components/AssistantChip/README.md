# AssistantChip
A gold cursor with a name pill, shown on the field the assistant is acting on, so its work is visible.

- Cursor in `gold`, pill `gold` with `on-gold` 12px medium text reading "Sisyphus".
- Attach it to the active field (`sy-field--active`) while typing; remove it when the assistant stops or hands over via `ApprovalCard`.
- The assistant is always named and always visible; never fill fields with no chip on screen.
